# ICEA 國際總會網站

這個 `docs/` 目錄是 GitHub Pages 發佈版本。

## GitHub Pages 設定

1. 把整個專案推到 GitHub。
2. 到 repository 的 `Settings -> Pages`。
3. `Build and deployment` 選 `Deploy from a branch`。
4. Branch 選你的主分支，例如 `main`。
5. Folder 選 `/docs`。
6. 儲存後等待 GitHub Pages 重新部署。

## 目錄內容

- `index.html`: 頁面入口
- `styles.css`: 樣式
- `app.js`: 前端互動
- `assets/data.js`: 會員資料
- `assets/icea-flag.jpg`: 旗幟圖片
- `.nojekyll`: 停用 Jekyll 處理，避免靜態資源被干擾
